# StoryTree v1.0.0

The first public Windows release of StoryTree, a local editor for game scripts and branching narratives.

- Build branching scenes with dialogue, monologue, condition, jump, event, and label nodes.
- Reuse character and item cards with independent scene snapshots.
- Simulate routes and see how conditions roll back pending event changes.
- Explore parallel branches or view nodes chronologically in the Story Tree.
- Connect an MCP-compatible AI agent through the included local stdio launcher.

## Download and run

Download **StoryTree-1.0.0-win-x64.zip** under **Assets**, extract the whole archive, and open `StoryTree.exe`. Use the attached `SHA256SUMS.txt` to verify the download. The app opens with a sample project and saves your own work locally in `data`.
