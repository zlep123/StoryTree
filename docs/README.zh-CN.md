# StoryTree 故事树 1.2.0

用于梳理剧情的本地 Windows 桌面软件。界面参考本机 Arrow 3.1：网格节点画布、曲线连接、缩略图、场景和分页检查器，并扩展角色卡、物品与可回溯的状态变化。

[下载 Windows x64 便携版](https://github.com/zlep123/StoryTree/releases/download/v1.2.0/StoryTree-1.2.0-win-x64.zip) · [两分钟中英实操教程](https://github.com/zlep123/StoryTree/releases/download/v1.2.0/StoryTree-1.2.0-Tutorial-ZH-EN.mp4) · [原 1.2.0 功能与插件演示](https://github.com/zlep123/StoryTree/releases/download/v1.2.0/StoryTree-1.2.0-Demo-ZH-EN.mp4)

## 1.2.0 更新

- 编辑器提供独立的「查找」和「替换」，跨节点替换支持预览、勾选字段及整批撤销。
- 场景地图支持框选和成组移动。地图图层可以单独隐藏或锁定。
- 本版还包含 TXT 剧本导入、Excel 素材导入、分段大纲、角色变量、对白日志、插件 API 1 和本地 MCP 入口。

## 启动

双击 `StoryTree.exe`，或 `启动故事树.cmd`。无需安装 Node.js、Python 或 npm，运行时已包含。整个文件夹需要保留，不能只移动 exe。

初次打开包含「雾港来信」示例。点击顶部故事名 → **新建空白故事**可开始自己的项目，也可以用「打开」导入仓库里的[空白故事](../examples/空白故事.storytree.json)。当前项目会自动备份。

所有数据都保存在软件目录的 `data`，不上传云端。项目主文件是 `data/story.storytree.json`，最近 40 次保存前的版本在 `data/backups`。角色形象和概念图存放在 `data/media`，由工作文件与备份共享。迁移工作目录请复制整个 `data` 文件夹。运行中会有本地数据服务供桌面与 MCP 共享项目，空闲 15 分钟后退出，需要时自动启动。

顶部的**保存**按钮与 Ctrl+S 都会立即提交待保存的编辑。自动保存继续运行。

## 从 TXT 导入剧本

1. 点击顶部的**导入剧本**，选择 `.txt` 文件，或点击**试用示例**。支持 UTF-8、带 BOM 的 UTF-16 和 GB18030。每次最多 1 MB、60 个场景和 500 个节点，节点数包含自动跳转。
2. 逐个场景查看预览。展开节点可读正文并核对原文行号。确认前可选择是否新建角色卡、是否用跳转连接场景。与项目内唯一同名角色匹配时，会复用该角色卡。
3. 确认后，新场景会追加到当前项目。场景内按原文顺序连接，整次导入可用撤销按钮恢复。

可识别 `场景：北门驿站`、`第三场 · 山路`、`# 雾港码头` 和 `INT. CABIN - NIGHT` 等场景标题。用 `米拉卡：这条船今晚还开吗？` 标注对白。英文剧本也支持把大写说话者单独写一行。普通段落、舞台描述等保留为独白。规则拆分适合当作初稿，建议按预览检查含冒号的段落和角色识别。

使用 `日期：1024.04.16`、`@date 1024-04-16` 或单独一行 `[1024.04.16]` 标注故事日期。也可在场景标题末尾加日期，例如 `# 山路 [1024-04-19]`。日期在同一场景内向后沿用。相对时间保留在正文里。故事树的分支会标出未定日期，可在检查器补填或清空日期。导出的项目含未定日期时，需要用支持未定日期的版本打开。

## 画布与节点

- 右击或双击空白画布，也可以点击「添加节点」，建立**对话、独白、条件、跳转、事件、标签**六种节点。
- 选中节点，在右侧检查器编辑名称、简介、日期和正文。文字停止输入约 0.75 秒后自动保存，离开输入框也会保存。
- 双击画布上方的场景页签或素材库里的场景名称即可改名。按 Enter 保存。
- 拖动标题栏移动节点；按 Shift 点选或拖动画布空白处框选；空格拖动画布，滚轮缩放。“适应画布”显示全部节点。
- 右侧检查器可切换项目、节点、场景、角色和物品。
- 素材库、检查器和故事树可用标题栏的箭头收起，再点击窄条展开。软件会记住各面板的开合状态。
- 左下角的齿轮打开**设置**。可切换中文或 English、选择字体、分别调整界面字号和节点字号，也可检查更新。默认缩放低于 45% 时切换到灰色方块概览，阈值可在设置中调整或关闭。
- 素材库底部、节点类型、故事日期和故事树的提示可单击隐藏。再次启动时会重新显示。
- 画布上方的搜索框同时搜索检查器和故事树内容，支持对白正文、日期、角色、物品和场景等信息。在文字编辑框外按 **Ctrl+F** 聚焦搜索框，上下方向键选择结果，回车定位。
- 点击来源节点右侧输出点，再点击目标左侧输入点建立连接。一个输入点可接受任意多条连线。双击连线可移除。
- 对话、独白和事件右边框的 **＋** 可新增输出点。条件固定真假两个；标签与跳转固定一个。
- Delete 删除所选节点；Ctrl+Z 撤销，Ctrl+Shift+Z 重做。关闭软件前会尝试提交当前节点的文字。

### 对白与引用

对话按句编辑，每句独立指定说话角色。**Enter** 新建一句并弹出角色框，**Tab / Shift+Tab** 切换角色，**Enter** 确定。**Shift+Enter** 在同一句中换行。中文输入法候选确认时不会误建句子。

在对话节点检查器中可以编辑**节点默认规则**，设置模式、参与角色和发言顺序。角色列表可添加旁白。轮谈按规则顺序切换说话人，对谈续写沿用当前说话人，也可手动切换。点击每句左下角的**规则**可以单独设置本句。只有点击**完成并续写**或按 Enter 才会插入下一句。新句继承来源句的规则，原有其他句子的规则保留。Shift+Enter 在当前句内换行。

画布中的对话以「说话人：内容」逐行显示。选中任意类型的节点后，点击检查器顶部的**节点日志**可查看完整文本，也可以导出为 UTF-8 TXT。

在对话或事件节点中，点击台词旁的「放大」可编辑长台词。「编辑对白日志」可以整段修改对白，每句以角色 ID 和冒号开头，冒号前留空表示旁白。用 Shift+Enter 在同一句内换行。

事件节点可以同时记录事件描述、待变化和逐句对白。事件对白支持同样的默认规则、逐句规则和续写，并显示在画布与节点日志中。

原有角色卡名称继续作为**角色ID**，建卡时填写，已有角色的 ID 固定。**角色名称**用于游戏内显示，留空时沿用角色ID。双击节点中的角色卡可修改角色名称、简介、详情、形象、分组、标签、技能、属性和物品。保存后在该节点生效。事件回溯时，角色资料变化和其他待变化一起回溯。

如果旧版的恢复副本含找不到原位置的草稿，打开文件时可在确认窗口展开**恢复草稿**并复制文字，也可在打开后的项目检查器查看。

独白只指定一次角色，也可以选择旁白，正文支持长篇描述。

角色卡或物品卡可拖入节点；也可拖到检查器正文输入框，在文本中插入 `@名称` 引用。画布正文会把引用显示为可双击的卡片模块。悬停卡片显示简介。

## 批量导入与概念图

- 在素材库的**角色**或**物品**页点击**导入 Excel**。可下载模板，也可选择已有的 `.xlsx`。把首行设为列名，每行填写一张卡片，至少填写「名称」。用「角色」和「物品」工作表可在一次导入中建立两类卡片。未使用这些名称时，程序按打开导入窗口的页签读取第一张表。
- 预览显示两类卡片的数量和示例。遇到错误时按表名和行号修改工作簿后重选。确认会新增卡片，已有同名卡片继续保留。整批可一次撤销。每次最多导入 2,000 张卡片，工作簿最大 5 MB。
- 在**物品**页新建分组，再将物品卡拖到组标题，或在卡片内选组。组标题可拖入节点，旁边的菜单可改组名和批量加标签。
- 在**概念图**页添加地图、角色设定图和场景参考图。支持 PNG、JPEG、WebP 和 GIF。单张最多 4 MB，一个项目合计最多 12 MB。点击图片可修改名称、分类和备注，或按原始尺寸查看。图片随项目保存和导出。

## 角色卡

双击素材库或检查器“角色”页中的卡片编辑。支持名称、图片、简介、详情、分组、标签、自定义技能、自定义属性和物品栏。

- 技能 0–10，默认 0。0 为未习得，6 为人类极限，7–10 超越人类。支持一键归零与保存。
- 属性 0–100，默认 20。可在全局设定中定义新角色默认栏位，也可在单张卡片内自由添加。
- 图片嵌入项目，支持 PNG、JPEG、WebP、GIF，最大 8MB。
- 物品支持堆叠；双击数量修改，0 表示失去该物品。双击物品名称可修改携带物品的属性。
- 角色分组支持批量添加标签、设定技能/属性、给予物品、加入场景；分组标题可以整组拖进节点。

### 当前设定、场景快照与节点变化

角色库保存可复用的当前设定。**首次加入场景**时复制一份独立快照；已经入场的历史不会被角色库后续修改覆盖。

检查器“查看状态”或角色卡的“编辑场景当前状态”，显示当前默认路径推演后的状态。这里保存的即时修改叠加在该场景已推演节点之后，同时更新角色库，供未来新场景使用。

双击**节点中的角色模块**打开的是“待变化”窗口。调整数值和物品后保存，变化属于该节点，在推演中生效。对话与独白也支持待变化；条件和跳转中的角色仅用于预览。

### 玩家命名、角色变量与地点

- 在任意节点的检查器打开 **待变化 → 添加变化 → 角色名称**，选择固定名称或由玩家输入。可编写提示语和默认名称。在 **剧情推演** 中到达该节点时可以试填，提交空白会使用默认名称，默认名称留空则沿用角色ID。
- 点击文本框旁的 **插入角色变量**，或从角色卡拖入变量。点击画布、检查器预览、节点日志或剧情推演中的变量链接，可以查看该节点上的完整值。检查器中的 **编辑文本** 会打开原有文本框。
- 在 **素材库 → 地点** 新建地点并选择颜色。双击现有地点可以新建子地点。画布以半透明虚线框包围地点及其下级地点。在框内右键或双击新建节点时，新节点会继承点击处层级最深的地点，范围随之扩展。
- 节点日志会导出命名提示、默认名称、输入 ID、变量及预览值和地点路径。项目 JSON 中，玩家命名保存在节点的 `operations[].input`，游戏可按 `prompt` 显示输入框，将单行答案应用到 `characterId` 的 `displayName`，并用 `input.id` 对应答案。正文变量使用 `{{char:角色内部ID:栏目[:子项[:属性键]]}}`，旧的 `{{attr:角色内部ID:属性键}}` 继续有效。节点的 `locationId` 对应 `project.locations`，地点的 `parentId` 指向上级地点。
- 在 **设置 → 检查更新** 查看 GitHub 已发布的版本。发现更高版本时可打开发布页下载。

## 事件、阵营与回溯

事件预设 **战斗、交易、自定义**。战斗与交易有 A/B 两个阵营，拖入角色即可分配；拖到另一个阵营会自动移出原阵营。自定义事件可命名。

“添加变化”支持修改角色属性、技能、物品数量、携带物品属性、标签，以及角色间物品转移。变更以原子方式推演，物品不足或超出范围会明确停止，避免生成不一致状态。

在**事件角色面板**中，把一个角色的物品拖给另一个角色，每次转移 1 件；需要转移多件时可使用“添加变化”。原主人减少、接收者增加，在同一笔操作中记录。面板内有物品素材托盘，可拖给角色表示新获得物品。

事件后的条件节点默认：**条件为假，回溯上一事件全部变化**。也可明确指定要回溯的事件，或仅豁免指定角色。转移涉及任意被豁免角色时，整笔转移不发生，物品不会凭空消失或复制。

条件还可设置“条件为真时回溯”，方便直接表达“如果米拉卡睡过头，则她没参加战斗”。结构化规则可选择读取事件发生前的角色状态。

条件支持两种判定：

1. **手动判定**：保留自然语言描述，由作者指定当前剧情结果。
2. **结构化规则**：比较角色属性、技能、物品数量、标签，支持 =、≠、>、≥、<、≤，以及全部/任一组合。

自由文字是创作描述，不会自动被当作可执行代码；AI 可通过 MCP 帮你建立对应的结构化规则。

## 物品与标签

A 组必选一个：副本物品、单机物品、特殊物品、任务物品。

B 组可选一个：装备、道具、材料、未知。

C 组可选一个：未知、普通、优质、稀世、异世、传说。选择 B 组后才可设置 C 组。特殊物品没有属性栏，其余物品属性范围 0–100。

标签节点可匹配角色或角色携带的物品。标签用逗号分隔，必须全部匹配。物品可用自定义标签、A 组名称、`类型:装备`、`品级:传说` 等匹配，批量修改物品数量、属性或进行转移。

携带物品的属性按“角色 + 物品种类”保存，同种物品堆叠共享一组属性；目前不为堆叠中的每一件物品单独编号。

## 场景、日期和故事树

点击画布上方的「场景地图」，双击地图上的地点范围或右侧地点卡即可进入子地图，点击「上一级」回到刚才的地图。素材库里的地点也可以双击逐层打开，使用卡片上的编辑按钮修改地点资料。把子地点卡从右侧列表或素材库拖到地图上即可布置，拖动范围调整位置，拖右下角调整大小。选中地点后可以连接路线、定位剧情节点，或在该地点新建节点。底图可选用概念图库里的图片。

将角色卡拖入地图，或用右侧的「放置角色」。再次拖入同一个角色会移动原有标记，双击标记可以打开角色卡。右侧可添加矩形、椭圆和三角形。选中物体可以改名、换颜色或移除，拖动右下角调整大小。场景总图和各子地图分别保存这些元素，剧情画布的「地图指引」和项目导出都会带上它们。

选中或右击地图物体即可复制、创建副本或删除。复制后可以切换到同一项目里的其他地图再粘贴。「自定义物体」支持选取图库图片或上传本地图片。

在地图空白处按住左键拖动，可框选地点、角色和物体。按住 Shift 可追加框选或逐个增减。拖动任一选中单位可移动整组，Delete 删除选中的地图布置。复制多个几何或图片物体时会保留它们的相对位置。

打开场景地图右侧的「地图图层」，可以分别隐藏或锁定底图、地点和路线、角色、物体。锁定的元素仍可见，可以在它们上方操作其他图层。图层偏好保存在本机。

每个场景分别保存自己的布局。回到剧情画布后，可用「地图指引」显示当前地图的地点范围和路线，在范围内新建的节点会继承对应地点。

新建场景是空白画布。角色或分组拖到场景页签后，会复制独立角色快照。框选多个节点，再选择移动/复制到场景，会保留选中节点间的内部连线。移动时，与未选中节点的外部连线会断开。

节点日期范围为 0001.01.01–9999.12.31。可直接输入日期，按回车或离开输入框保存。也可打开日历按钮，分别滚动选择年、月、日，再点击**应用日期**。新节点继承当前场景上一节点的日期。

故事树位于检查器右侧，默认按连线显示分支。同一节点的后续分支横向并排，汇合和回连用虚线卡片引用已有节点。日期与地点用范围框标出。点击节点可定位到画布，悬停可读摘要和可用的状态变化。

“推演剧情”可切换条件真假及分叉，查看每个节点前后的角色变化。互斥分支不会合并；未选择分支时停在分叉处。遇到循环会停止，防止重复扣物品。跳转节点可指定任意场景/日期的目标，跳到另一场景时使用那个场景自己的独立角色状态。

回溯适合“事件 → 条件”的直接关系。跨越复杂、嵌套回溯时，软件可能提示把条件紧接对应事件，以避免不明确的历史重算。

### 在故事树阅读剧情与编写大纲

- **分支**图中的卡片直接显示日期和带色标的地点。连线经过不同日期或地点时会标出变化。
- **剧情概要**按实际连线和跨场景跳转展示节点简介、正文及对白摘录。可以指定阅读起点，在分支处选择接下来的路线。点节点标题可以回画布定位。
- 点故事树标题旁的 **展开** 可获得更大的阅读和写作区域。**新建大纲** 可以写下计划、设置开始和结束日期，并指定地点。日期范围包含首尾。填一端表示开放范围，两端留空时不限日期。指定父地点会纳入所有子地点。大纲卡片会列出范围内的现有节点。
- 故事树搜索可以查找节点和大纲，也可叠加日期与地点筛选。剧情概要保留完整路线，并标出筛选范围外的节点。
- 大纲随项目保存和导出。MCP 可用 `storytree_get_story_route` 读取实际连接，并通过 `storytree_batch` 执行 `outline.create`、`outline.update` 或 `outline.delete`。
- 大纲正文支持插入节点、场景、角色、物品、地点、概念图、分组、大纲和角色变量的链接。在编辑器右侧拖入或点击素材，保存后点击链接打开目标。也可把画布节点的拖动把手或素材库卡片拖到现有大纲卡上，直接追加链接。

## MCP：连接 Codex、DeepSeek Harness 等

专用入口是 **`D:\storytree\StoryTree.MCP.exe`**，提供纯 stdio MCP，无需额外安装 Node.js。首次调用会自动启动本地数据服务，不必先打开主界面。Windows 10/11 内置的 .NET Framework 用于这个小型入口；同目录提供 cmd 备用入口。

软件顶部 **AI / MCP** 会生成当前实际路径的配置。如果你移动了软件文件夹，请从该窗口重新复制配置。

Codex 的 `config.toml` 配置片段：

```toml
[mcp_servers.storytree]
command = 'D:\storytree\StoryTree.MCP.exe'
args = []
```

DeepSeek Harness / 通用 MCP JSON：

```json
{
  "mcpServers": {
    "storytree": {
      "command": "D:\\storytree\\StoryTree.MCP.exe",
      "args": []
    }
  }
}
```

接入时从软件内复制实际安装路径的配置，并将相应条目合并到 agent 已有配置中。

如果需要多个独立项目，可给 MCP 入口传入 `--data` 和一个独立数据目录；主程序也支持相同参数。

### 工具与数据规则

提供 25 个工具，可读取项目、场景、角色、故事树和剧情路线，编辑节点和连线，管理场景、角色、物品、地点及大纲，进行剧情推演、原子批量编辑和撤销重做。

可读取 `storytree://schema` 获取字段与回溯规则，`storytree://project` 获取完整项目。所有写入和桌面使用同一服务，写入保存后界面会自动刷新；正在编辑文本时会暂缓远端刷新。AI 操作记录在项目的 `audit` 中。

一个事件操作示例：

```json
{
  "kind": "transfer",
  "characterId": "原主人角色ID",
  "toCharacterId": "接收角色ID",
  "itemId": "物品ID",
  "value": 1
}
```

条件中的 `rollback` 为 `all` / `selected` / `none`，`excludedCharacters` 指定豁免的角色 ID。`rollbackWhen` 为 `false`（默认）或 `true`；`evaluateAt` 为 `current`（默认）或 `beforeEvent`。

## 插件

顶部「插件」可以安装、更新、启用或卸载本地插件。点击「安装示例插件」可试用场景检查。生成的大纲等项目修改会先显示预览，点击「应用修改」后保存。编写插件请参阅安装目录下的 docs/PLUGINS.md。

下载[场景计数插件](../examples/scene-count.storytree-plugin.json)后，用「安装或更新插件」选择文件，启用后点击「统计节点」即可运行。按[插件指南](PLUGINS.md)可继续编写 API 1 插件。

## 查找和替换

节点检查器、对白窗口和大纲分别提供「查找」和「替换」按钮。文字编辑框内按 Ctrl+F 打开查找，按 Ctrl+H 打开替换。可替换当前匹配或当前字段内的全部匹配，大纲超链接和角色变量会保留。

要跨节点替换，点击画布搜索栏旁的「替换」，输入旧词和新词，选择当前场景或全部场景。点击「预览替换」后，勾选要修改的字段并点击「替换选中项」。一次撤销可还原这批改动。

## 保存、备份与源代码

- 自动保存使用临时文件写入后替换，保存前保留备份。
- 使用「导出」可生成自带图片的独立 `.storytree.json`，也可交给支持相应功能的旧版打开。恢复本机的自动备份时，可在「打开」中选择 `data/backups` 下的 JSON，程序会从同一 `data` 目录加载图片。
- 撤销/重做历史保存在当前数据服务内；重启数据服务后请使用自动备份恢复更早版本。
- GitHub 仓库包含可编辑源码和数据层测试。便携包运行 `resources/app` 中的代码。修改前可先导出项目。
- 在仓库根目录运行 `npm ci` 安装依赖，再运行 `npm test`、`npm start` 或 `npm run build`。构建目录默认为 `dist/StoryTree-1.2.0-win-x64`，Windows 入口使用系统的 .NET Framework C# 编译器。若 npm 跳过了 Electron 安装脚本，可运行 `node node_modules/electron/install.js` 安装运行时。
- 日志在 `data/startup.log` 与 `data/service.log`。本地服务只监听 127.0.0.1，并验证访问令牌；不需要开放防火墙端口。
- 便携版在本机保存项目。「检查更新」可以打开新版下载页，另存和迁移项目可使用「导出」。

实现参考：Electron 官方桌面隔离建议（https://www.electronjs.org/docs/latest/tutorial/security）及 MCP 2025-11-25 stdio / tools 规范（https://modelcontextprotocol.io/specification/2025-11-25）。
